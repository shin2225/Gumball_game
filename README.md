# 🌋 ガムボール・ボルケーノ

ゲームセンターの「左右ハンドルで棒を上げてボールを運ぶ」タイプのゲームを、火山テーマで再現したブラウザゲームです。静的ファイルだけで動きます。

## 遊び方
- 「100円入れる」でスタート（1プレイ3球）
- 左右のハンドルで棒の両端を上げ下げし、ガムボールを**光っている番号の穴**まで運ぶ
- ほかの穴に落ちるとアウト。①→②→…→⑩（火口）の順に挑戦し、火口に入れると大噴火

### 操作
| | 左ハンドル | 右ハンドル |
|---|---|---|
| スマホ | 画面左半分を上下ドラッグ | 画面右半分を上下ドラッグ |
| キーボード | `W` / `S` | `↑` / `↓` |

ベスト記録と累計ガム数は localStorage に保存されます。

## ファイル
- `index.html` … ガムボール・ボルケーノ
- `gumball.html` … ふつうのガムボールマシン（ハンドルを回してガムを出す）

## GitHub Pages で公開する
**Settings → Pages → Build and deployment** で Source を `Deploy from a branch`、Branch を `main`（`/ (root)`）にすると公開されます。

# 🧩 CPU 五層ビュー（`cpu/`）

小さな 8bit CPU を **C → アセンブリ → 機械語 → 論理回路 → チューリングマシン** の 5 層で同時に動かし、**動作フローチャート**を加えた 6 つのビューで見るビジュアライザです。`cpu/index.html` を開くだけで動きます（ビルド不要）。

- 5 層はそれぞれ**独立した定義**で同じプログラムを実行し、1 命令ごとにレジスタ・フラグ C・PC・停止状態を突き合わせます（右上の「一致 ✓ 5/5」）
  - C: 構文木を C の意味論で解釈 / ASM: ニーモニックの意味で解釈 / 機械語: 16bit 語をオペコード表で解読
  - 回路: ゲート 639 個のネットリストを評価する単一サイクル CPU（レジスタ 8 本、ROM 64 語、読み出しポート 2 つ、フラグ C）
  - TM: 状態 387 個・遷移 1672 本の δ だけで、テープ（= 機械語そのもの + レジスタ + C）を書き換える
- 命令: `INC DEC ADD SUB MOV SHR JZ JNZ JC JNC JMP HALT`（書式 `oooo rrr sss aaaaaa`）
- 表示は **俯瞰 / 詳細 / 全体（高負荷）** の 3 種。回路は基板と 2 進数を重ねた俯瞰図と、ゲートレベルの回路図
- **TM のロジック解説**: TM の擬似コードと各状態の対応、「なぜこの遷移か」（直前の δ と、その段階のねらい、CPU のどの部品に当たるか）
- **フローチャート**: C の構文木から構造化フローチャート（端子・処理・判断）、アセンブリ直接のときは基本ブロックの CFG
- どの動きもホバーで「どの定義で動いているか」が見られます。`定義トレース`（T キー）と `定義一覧`（D キー）でも確認できます
- C の部分集合: `unsigned char` 変数 8 個まで、`x++` `x--` `x = 式`（定数 / 変数 / 変数±変数 / 変数>>k / 変数<<k）`x += y` `x -= y` `x >>= k` `x <<= k`、条件 `x` `!x` `x == y` `x != y` `x < y` `x <= y` `x > y` `x >= y`、`while` `for (;;)` `if … else` `break` `return`

サンプル: ニュートン法（⌊√200⌋ = 14）、オイラー法（指数減衰・自由落下）、ユークリッドの互除法、フィボナッチ数、2 進の掛け算（シフトと加算）など。

| キー | 操作 |
|---|---|
| Space | 実行 / 一時停止 |
| → / Shift+→ | 1 命令 / TM 1 ステップ |
| E | 最後まで一気に |
| R | リセット |
| 1 / 2 / 3 | 俯瞰 / 詳細 / 全体 |

テスト: `node cpu/test.js`（全サンプルとランダムなプログラムを 5 層で実行し、毎命令の一致と結果を確認）
