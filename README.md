# 🌋 ガムボール・ボルケーノ

ゲームセンターの「左右ハンドルで棒を上げてボールを運ぶ」タイプのゲームを、火山テーマで再現したブラウザゲームです。静的ファイルだけで動きます。

## 遊び方
- 「100円入れる」でスタート（1プレイ3球）
- 左右のハンドルで棒の両端を上げ下げし、ガムボールを**光っている番号の穴**まで運ぶ
- ほかの穴に落ちるとアウト。①→②→…→⑩（火口）の順に挑戦し、火口に入れると大噴火

### 操作
| | 左ハンドル | 右ハンドル |
|---|---|---|
| スマホ | 画面左半分を上下ドラッグ | 画面右半分を上下ドラッグ |
| キーボード | `W` / `S` | `↑` / `↓` |

ベスト記録と累計ガム数は localStorage に保存されます。

## ファイル
- `index.html` … ガムボール・ボルケーノ
- `gumball.html` … ふつうのガムボールマシン（ハンドルを回してガムを出す）

## GitHub Pages で公開する
**Settings → Pages → Build and deployment** で Source を `Deploy from a branch`、Branch を `main`（`/ (root)`）にすると公開されます。
