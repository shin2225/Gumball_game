# 🍬 ガムボールマシン

ゲームセンターによくあるガムボールマシンのブラウザゲームです。静的ファイル（`index.html` 1枚）だけで動きます。

## 遊び方
1. 左下の **コイン** をタップして投入
2. 中央の **ハンドル** をぐるっと1周回す
3. 出てきたガムを **タップ** して取り出す（コレクションに記録されます。ゴールドはレア）

記録はブラウザの localStorage に保存されます。

## GitHub Pages で公開する
リポジトリの **Settings → Pages → Build and deployment** で、Source を `Deploy from a branch`、Branch を `main`（`/ (root)`）にすると公開されます。
